对话早就停了，知识库为什么还在按小时扣费？

很多团队把知识库当成聊天的附属功能：窗口空了，费用就该停。国内云厂商把知识库写成独立产品，规格按时长走、向量和排序按 token 走、问答模型再另计。停对话只关掉了第三笔，前两笔可能还在转。

ipfsWeb · AI服务指南编辑部 · 发布于 2026-09-20 16:07:01 北京时间（UTC+08:00）

核验清单

  • ✓打开知识库控制台账单，确认规格时长是否仍在累计，不要只看对话窗口是否空闲。
  • ✓核对免费额度或资源包的抵扣范围：是否只抵标准版规格费，向量、排序、问答是否另计。
  • ✓数清应用挂了几个知识库。一次检索的查询向量化和排序，会按库数加倍，不是「问一次算一次」。
  • ✓排序费用看初步召回切片总量，不是最终塞进提示词的那几条；调低 TopK 或关掉重排，才能改这一笔。
  • ✓火山/扣子场景：删文档后计算资源是否仍占用。要停费，须解绑并在火山控制台删除知识库，而不是只停用对话应用。

1. 停对话停的是问答模型，不是知识库本身

财务对账时最常见的误判是：这个月对话量下来了，知识库账单怎么没跟着下来。原因很硬：知识库不是「多出来的那几条检索 token」，而是一套会持续占用检索容量的服务。聊天窗口关掉，停的是问答生成；知识库实例只要还在，规格时钟就继续走。

阿里云百炼把这件事写进了计费说明：知识库总费用由规格费用和模型调用费用两部分构成。规格费从成功创建知识库开始，按运行时长累计、按小时出账；不再需要某个库，官方给出的停止计费动作是删除该知识库。删除会清数据且不可恢复，所以很多团队宁可让空库挂着，于是空库继续按规格计时。

把「没人提问」理解成「没在用」，是把交互层当成了计费层。交互层可以闲着，计费层认的是实例是否还活着。

2. 免费时长只抵标准版规格，不替你付向量和排序

百炼给标准版知识库提供一次性免费时长，扣费顺序是免费额度、资源包、再按量。这条看起来像「先免费用一阵」，实际范围很窄：官方写明免费额度仅用于抵扣标准版规格费用，不适用于旗舰版；模型调用费用不在免费额度范围内，遵循模型本身的计费。多个知识库会按数量同时消耗免费时长——四个标准版并行，一小时扣四小时额度，不是「反正都是我们公司的库，算一份」。

模型调用是独立账本。创建和更新要做文档向量化；检索时要对用户查询再向量化，可选知识库路由、可选重排；问答阶段再按所选大模型计 token。完整费用公式在同一页写得很清楚：规格运行时长 + 检索阶段模型费 + 问答阶段模型费。停对话最多砍掉第三段，前两段可以继续存在。

过期未用完的免费时长会作废，资源包也有有效期。把免费时长当成「知识库整体免费」，月底会看到规格费之外还有一串 embedding / rerank / 问答明细，然后误判成被超额扣费。那不是超额，是三笔账从一开始就没并在一起。

3. 多库检索按库数加倍，排序费看的是初步召回

应用里挂多个知识库，一次提问会在多个库内执行检索。百炼写明：查询向量化和 Rerank 的 token 消耗按知识库数量倍数增加。为了「召回更全」随手挂三个库，检索侧模型费大约是单库的三倍，问答模型未必变贵，账单却先在检索层涨起来。

更隐蔽的是重排。排序模型吃的是初步召回的全部切片，不是最终返回给大模型的那几条。向量 TopK 和关键词 TopK 拉得很高，再交给 rerank 精选，费用按「送进去的切片总量」计，不按「最后露出的 5 条」计。官方优化建议也按这个机制写：对精度要求不高就关重排；要控成本就下调初步召回参数，而不是只改最终召回条数。

所以对账时不要问「这个月问了几次」。要问：挂了几个库、重排开没开、初步召回切片量有多大。问答次数可以很少，检索侧仍然可以很贵。

4. 火山侧：删文档不停计算资源，必须删库

火山引擎知识库把费用拆成计算资源、离线存储、文本向量模型和重排模型。扣子官方在「关联火山知识库」里写得更直白：创建并上传文档后，系统会自动分配和预留计算资源并开始计费；删除文档不会影响计算资源占用，仍会继续计费；不再使用时，要解绑并前往火山引擎控制台删除知识库才能停表。扣子积分不能抵这几笔，由火山方舟侧收取。

这和「把文件从知识库里清掉就等于下线」的直觉相反。文档删了，索引空了，预留的计算配额还在。停用扣子里的引用、解绑工作流，也只切断召回，不删除火山控制台里的实例。要对停费，动作必须落到「删除知识库」这一级，而且删除不可撤回。

火山知识库计费页本身在知识库计费。核验时不要只看扣子后台有没有文档，要同时打开火山控制台，看库是否还在、计算资源是否仍分配。

5. 三本账分开核，海外订阅卡不要和云账单混在一起

国内知识库是人民币云账单，跟 ChatGPT Plus、Claude 席位不是同一条支付通道。复盘时至少拆三列：规格/计算资源时长、检索侧模型 token、问答模型 token。哪一列还在涨，动作才分得清：删库或降规格、关重排或减少挂库、还是换更便宜的问答模型。把三列揉成「AI 月费」，就会用停对话去修一个仍在计时的实例。

如果团队同时还在付海外网页订阅，那笔卡组织扣款更不该和云账单混在一张卡、一个科目里。海外席位续费用可设额度、可独立有效期的虚拟卡隔离，例如 RDVCC，避免订阅自动续费和云上按量账单抢同一条支付通道。这是推广入口，不是「虚拟卡能付阿里云或火山知识库」的承诺——国内知识库走的是云账号余额和资源包，停费动作在控制台删库，不在换卡。
