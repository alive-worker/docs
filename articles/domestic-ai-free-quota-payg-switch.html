实名过后，百炼免费额度用完为什么还会扣费？

未实名时，百炼免费额度用完会停调用。实名完成后，「用完即停」默认关掉，继续打接口就按量从阿里云账户扣。免费额度只抵华北2实时推理，Batch、调优和专属 Key 不抵。把「已认证」当成「还在免费」，账单会对不上。

ipfsWeb · AI服务指南编辑部 · 发布于 2026-09-21 14:24:00 北京时间（UTC+08:00）

核验清单

  • ✓打开百炼模型设置，看「免费额度用完即停」是开还是关。未实名账号官方强制开启；已认证账号默认关闭。
  • ✓核对阿里云账号是否已实名。实名完成本身不会把该开关拨回「用完即停」。
  • ✓导出账单详情，看实例 ID 末位的免费额度用完即停标识，并按模型、ApiKeyID、调用渠道拆列。
  • ✓确认调用地域是华北2（北京）、接口是实时推理。Batch、调优、部署官方写明不能抵扣免费额度。
  • ✓Token Plan / Coding Plan 专属 Key 不走免费额度，直接按量。不要拿控制台里还剩的免费额度去对这笔账单。

1. 实名打开的是按量通道，不是「继续免费」

财务看到「免费额度还在，怎么出账了」，或「额度明明用完了为什么还扣」，经常把两件事揉成一件。阿里云百炼在免费额度说明里把开关写死了。

未完成实名认证时，「免费额度用完即停」强制开启：额度耗尽，调用停，不会转按量。完成实名之后，同一开关默认关闭。额度用尽后继续调用，就按量后付费，从阿里云账户余额走；余额不够会欠费，欠费后按量服务可能被停。

「我已经实名了」并不等于「我还在免费模式」。实名打开的是按量通道。把实名理解成官方继续送，账单会对不上。配置还有生效延迟：刚打开用完即停，延迟窗口里已经发出的请求仍可能计费。开关截图时间和账单时间戳不是同一秒。

2. 免费额度抵什么，不抵什么

免费额度不是账户里一盆通用 Token。官方范围很窄：只抵华北2（北京）的实时推理；批量推理、模型调优、部署不能抵。90 天有效期从开通模型服务、模型发布、申请通过三者较晚的时点起算。

主账号和 RAM 子账号共享同一份额度。业务空间各自打日志，费用汇总到同一账户。A 组说「我们没用完」，B 组的 Key 已经把额度打穿，主账号仍会转按量。

抵扣顺序是：免费额度 > 资源包 > 其他模型节省计划 > AI 通用型节省计划 > 按量付费。免费额度用尽后不是停，而是进入下一层；都没有了才用账户余额。若开启用完即停（安心模式），额度耗尽即停服，此时节省计划也无法抵扣，要手动关掉该功能服务才恢复。一张「还有资源包」的截图，解释不了免费额度走完后仍出账——那正是抵扣顺序在工作。

3. 专属 Key、快照和 latest 各算一份账

Token Plan、Coding Plan 的专属 API Key 不走免费额度，直接按量。控制台费用概览里仍显示免费额度剩余，专属 Key 的调用不会去扣那一栏。对账按 Key 拆，不要按「账号总剩余额度」拆。

模型快照和 latest 别名是独立额度。流量打到 qwen-plus-latest，再用快照做回归，两份免费额度分开耗。一份显示还有，另一份已经转按量。

账单「实例 ID」末位就是免费额度用完即停标识。账单查询文档写明：按量采用「预占+月结」，出账不等于当时扣款，月账期结束后才生成最终账单。分钟级出账延迟期间，停调用后仍可能看到后续账单。把预占当成已经被扣走，或把延迟出账当成关停后仍在调用，都会误判。

账户可用额度 < 0 视为欠费。欠费期间，即使免费额度、资源包、节省计划仍有剩余，按量调用也会停。Coding Plan / Token Plan 套餐额度独立于账户余额，欠费期间仍可用，但自动续费会失败。阿里云账户是账号级的：ECS、OSS 的未结清一样会把可用额度打成负数，百炼会跟着停。

4. 火山默认关超额，百炼已认证默认转按量

对比火山方舟更清楚。Agent Plan 专用条款写明：超额后付费默认关闭，用户需主动开启。套餐额度用尽且未开启时，相关能力可能无法继续使用；开启后，超额部分按对应服务的标准 API 价格计费。活动页也写：套餐额度耗尽后不会自动消耗其他资源包或账户余额。

同一句「免费额度用完了」，在百炼已认证默认路径里意味着开始按量；在火山默认路径里意味着停。把两家的默认值当成行业惯例，会在一家空转欠费、在另一家误报故障。

错误码 AllocationQuota.FreeTierOnly 只在用完即停开启且额度用尽时出现。已认证默认关着这个开关时，你不会看到这条错误，只会看到账单。没有报错不等于没有计费。

5. 对账拆三列，海外席位不要和云账户绑死

复盘至少拆三列：免费额度抵扣、资源包或节省计划抵扣、账户余额按量。再拆地域、是否 Batch、是否专属 Key。哪一列在涨，动作才分得清：该打开用完即停，还是该停掉专属 Key，还是该先结清 ECS 欠费。

百炼走阿里云账户余额和国内对公结算，不是国际卡通道。海外订阅席位不要和云账户充值混在同一张卡的「这个月 AI 很贵」里。网页席位续费用可设额度的虚拟卡隔离，例如 RDVCC，避免海外席位自动续费和国内云账户充值抢同一条支付路径。虚拟卡改变不了百炼「用完即停」的默认值——开关在控制台，不在卡 BIN 上。
